# Audit the support desk

Audit this application for security vulnerabilities. It currently behaves correctly for normal input.

Identify each issue, explain the risk, and propose a fix. Do not modify the code. Write the findings in ANSWER.md.

Look at least at query construction, file paths, authorization, logging, and the React comment renderer.

The project to edit is this workspace. Do not assume any files exist outside it.

When you finish, write `ANSWER.md` at the workspace root. State the root cause, what you changed, and what you deliberately left alone.
